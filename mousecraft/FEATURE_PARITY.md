# Сравнение с Mac Mouse Fix

Дата исследования: 2 октября 2026. Установленное приложение изучено через живой
интерфейс: **3.0.8 (24310)**. Также использована публичная [страница функций](https://macmousefix.com/).
Видимые настройки: Regular, обратное направление, Medium, Precision выключен,
модификаторы ⇧/⌘/⌃/⌥; Trackpad Simulation выключен. Список Remaps пуст.
Исходная конфигурация установленного приложения не изменялась.

| Возможность | MouseCraft 0.1.0 | Что ещё проверить / реализовать |
|---|---|---|
| Плавная прокрутка | Собственный алгоритм, 3 режима, регулируемая скорость | Ощущение на физической мыши; инерционные фазы |
| Реверс только мыши | Дискретное колесо | Высокоточные колёса требуют HID-различения |
| Точная/быстрая/горизонтальная прокрутка | Настраиваемые модификаторы и коэффициенты | Поведение в приложениях |
| Precision при медленном колесе | По величине дискретного события | Настройка под разные колёса |
| Zoom с модификатором или кнопкой | Клавиши; экспериментальный нативный pinch | Доставка в Safari/Preview |
| Щелчки, многократные щелчки, удержание | Одинарный/двойной/тройной; конфигурируемая задержка | Физическое устройство |
| Click-and-drag | Четыре направления и порог | Интерактивные непрерывные переходы Dock |
| Click-and-scroll | Вверх/вниз, однократные и повторяемые действия | Натуральные скорости жестов |
| Look Up и Quick Look | Системная комбинация / пробел | Контекст, включённые системные сочетания |
| Mission Control / Exposé / показать стол | Существующие symbolic hotkeys с defaults | Нет отслеживания анимации Dock за указателем |
| Рабочие столы | Системные сочетания слева/справа | Нет интерактивного Dock swipe |
| Launchpad | Системная комбинация / приложение, иначе «Программы» | Современный аналог списка приложений |
| Назад/вперёд | Клавиши; экспериментальный native swipe | Совместимость и интерактивные жесты |
| Действия свайпа в Mail/Messages | Доступны фазовая горизонтальная прокрутка и native swipe | Реальный результат пока не подтверждён |
| 360° прокрутка холста | Отдельный панорамирующий жест, X/Y и сглаживание | Физическая мышь и приложение |
| Smart Zoom | Экспериментальное событие, AppKit распознаёт smartMagnify | Реальные приложения и версии macOS |
| Trackpad Simulation | Начало / изменение / конец прокрутки | Отдельные фазы momentum и rubber band |
| Фиксация указателя | Опция для распознаваемого движения с кнопкой | Физический event tap |
| Строка меню и пауза | Есть | Повседневная проверка |
| Работа после закрытия окна | Есть | Повседневная проверка |
| Автозапуск | SMAppService, настройка пользователя | Постоянный путь к .app, разрешение macOS |
| Проверка обновлений | Нет | Подписанный канал релизов и механизм обновления |
| Цена / активация | Полностью бесплатно, MIT | Нет платного функционала |
| Профили приложений | Наследование, исключения, свои кнопки/прокрутка | Ручная проверка переключений |
| Импорт/экспорт | JSON, валидация, резервирование нечитаемого файла | Нет импорта формата MMF |
| Диагностика | Последнее событие и активное приложение | HID-инвентарь и профили устройств |

Контрольные тесты проверяют расстояние прокрутки на 60/120/144 Гц, смену
направления, фракционные события, модификаторы, click/hold/drag/scroll/pan,
задержанные двойные щелчки, профили, импорт и AppKit-декодирование нативных жестов.
Они не подменяют испытания глобального event tap и реальной мыши.

Недокументированные числовые поля событий исследованы по публичным определениям
ABI и проверены через AppKit. Алгоритмы, интерфейс и файлы программы реализованы
самостоятельно. Код, ассеты и механизм лицензирования MMF не включены в приложение.
