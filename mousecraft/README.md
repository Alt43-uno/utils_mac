# MouseCraft

Бесплатная утилита для колёсных мышей на macOS: плавная прокрутка, назначения кнопок,
жесты и профили приложений. Своя реализация на Swift, AppKit и SwiftUI; лицензия MIT
из корня репозитория. Нет подписки, пробного периода, аккаунта, телеметрии или
проверки лицензии.

**Версия 0.2.0 — первый публичный релиз.** Это ранняя версия: ядро и формат
нативных жестов проверены 43 автоматическими тестами; совместимость с конкретными
мышами и приложениями требует проверки на устройстве.

## Установка

[Скачать DMG для Apple Silicon и Intel](https://github.com/Alt43-uno/utils_mac/releases/download/mousecraft-v0.2.0/MouseCraft-0.2.0-universal.dmg) ·
[Скачать PKG](https://github.com/Alt43-uno/utils_mac/releases/download/mousecraft-v0.2.0/MouseCraft-0.2.0-universal.pkg) ·
[Контрольные суммы SHA-256](https://github.com/Alt43-uno/utils_mac/releases/download/mousecraft-v0.2.0/MouseCraft-0.2.0-universal.sha256).

Готовые установщики создаются в `dist`: **MouseCraft-0.2.0-universal.dmg** и
**MouseCraft-0.2.0-universal.pkg**. Откройте DMG, перетащите MouseCraft в Applications
(«Программы»), извлеките диск и запустите приложение из «Программы».
PKG устанавливает приложение в `/Applications`, даже если есть копия в папке сборки.
Перед обновлением завершите MouseCraft через его меню. Настройки сохраняются.
Это сборка с подписью ad hoc; установщик не подписан сертификатом
Developer ID и не прошёл notarization.

Для установки из исходников:

```sh
cd mousecraft
./Scripts/install_app.sh
# Создание DMG и PKG:
./Scripts/make_installer.sh --no-build
```

Скрипт установки сохраняет прежнее приложение в
`~/Library/Application Support/MouseCraft/PreviousInstall.*` и не запускает его
автоматически. Запустите `/Applications/MouseCraft.app` после установки.

## Сборка

macOS 13+, Apple Silicon или Intel, Swift 6.0+ / актуальные Command Line Tools.
Для тестов требуется Swift Testing; текущая комплектная Testing.framework имеет
минимальную версию macOS 14. Сборка приложения не включает эту библиотеку.

```sh
cd mousecraft
./Scripts/build_app.sh --universal
./Scripts/run_tests.sh
```

Без `--universal` сборка создаётся для текущей архитектуры. `--debug` включает
отладочную конфигурацию. Имя установщика указывает его архитектуру.
Можно указать `CODESIGN_IDENTITY` для подписи сертификатом и `MOUSECRAFT_SDK`
для выбора SDK. Без сертификата сборка подписывается ad hoc, поэтому после
пересборки macOS может потребовать повторно выдать разрешения.

При несогласованных версиях Command Line Tools скрипты могут использовать
локальную копию **public**-интерфейса PackageDescription в `.build`. Если SDK 27
требует отсутствующий плагин SwiftUI, выбирается установленный SDK 26.5.
Системные файлы не изменяются. В обычной согласованной установке toolchain работают
стандартные `swift build` и `swift test --disable-xctest --enable-swift-testing`.

Для повседневного использования перенесите `build/MouseCraft.app` в постоянную
папку, например `/Applications`, и выдавайте разрешения именно этой копии.

## Первый запуск

1. Выключите обработку мыши в Mac Mouse Fix или другом обработчике событий.
2. Откройте установленный MouseCraft → «Обзор». Через кнопки настройки перейдите в
   «Универсальный доступ» и «Мониторинг ввода» и разрешите MouseCraft вручную.
3. Включите MouseCraft переключателем внизу окна. После выдачи «Универсального доступа» приложение
   проверяет разрешение автоматически. При необходимости нажмите «Проверить
   разрешения и подключение» или перезапустите приложение.
4. Откройте «Прокрутка», проверьте направление и скорость на тестовом списке.
5. Номера боковых кнопок отображаются в «Обзор → Диагностика» после нажатия.

Первая установка выключена по умолчанию. Закрытие окна не завершает обработку:
пауза и выход доступны в строке меню. Автозапуск включается пользователем в
«О приложении» через `SMAppService`.

Если прокрутка не меняется, проверьте фактический статус: **«Обработка работает»**.
Включённый переключатель с надписью «Не подключено» означает, что ядро остановлено;
причина показывается на каждой вкладке. «Мониторинга ввода» недостаточно для
изменения прокрутки: нужен «Универсальный доступ» именно установленной копии.
В диагностике видны путь приложения и счётчики полученных, обработанных и
пропущенных непрерывных событий. После пересборки локальной подписи macOS может
потребовать повторное включение разрешения.

## Интерфейс

Нативная панель разделов macOS и сгруппированные формы SwiftUI. Разделы доступны
мышью и через меню «Вид» / ⌘1–⌘5; активный раздел подсвечивается в панели окна.
Общий переключатель и фактический статус подключения видны внизу каждой страницы.
Диагностика, подсказки и экспериментальные параметры раскрываются по необходимости.
Раскрывающиеся строки реагируют на нажатие по всей ширине и используют короткую
пружинную анимацию без отскока. При «Уменьшении движения» анимация отключается;
при «Уменьшении прозрачности» нижняя панель становится непрозрачной.
Системные шрифты, цвета и элементы управления следуют оформлению macOS.

## Возможности

- Сглаживание с сохранением суммарного расстояния, независимое от частоты кадров.
  Быстрое прекращение старого движения при смене направления. Таймер работает
  только во время прокрутки или незавершённого жеста.
- Плавность: без сглаживания, баланс, плавно; скорость ×0.1–4, реверс и точность
  медленного колеса.
- Настраиваемые модификаторы: горизонтальная ось, масштаб, скорость ×3,
  точность ×0.25. Потреблённые модификаторы удаляются из синтетической прокрутки.
- Кнопки 3–32: щелчок, двойной/тройной щелчок, удержание, четыре направления
  движения, колесо при удержании и прокрутка 360°. Первичные кнопки 1/2 не
  переназначаются. Стартовый пресет рассчитан на мышь с 3 кнопками; доступен
  отдельный пресет для 5 кнопок.
- Mission Control, App Exposé, показать рабочий стол, рабочие столы слева/справа,
  словарь, Quick Look, переходы в браузере, масштаб, вкладки, буфер обмена,
  undo/redo, клики, своя клавиатурная комбинация, открытие выбранного приложения.
- Запись сочетания клавиш. Настройки задержки удержания, порога движения и
  фиксации указателя.
- Экспериментальные нативные pinch, Smart Zoom и свайпы. Фабрика проверяет, что
  AppKit распознаёт созданное событие, прежде чем разрешить отправку. Нативный
  масштаб включается отдельно; есть отдельный пресет нативных назначений.
- Симуляция трекпада через фазы прокрутки; фазовая прокрутка 360°.
- Профили по bundle ID активного приложения: исключение из обработки,
  отдельная прокрутка, отдельные кнопки или наследование общих настроек.
- Экспорт и импорт JSON с валидацией. Импорт не включает обработку автоматически.
  Неизвестная версия, повторяющиеся правила, недопустимые кнопки и сочетания
  отклоняются; числовые параметры ограничиваются разумными диапазонами.
- Диагностика последнего события, строка меню, обработка сна/пробуждения,
  переподключение отключённого event tap и обнаружение помощника Mac Mouse Fix.

## Средняя кнопка и холсты на сайтах

В «Кнопки и жесты» отключите **«Включить кнопки и жесты»**. Раздел перестаёт
перехватывать кнопки, включая удержание и движение средней кнопки: сайт получает
исходные события для перемещения по холсту. Плавная прокрутка и её настройки
продолжают работать. Сохранённые назначения не удаляются; их можно вернуть
переключателем. Выключение действует и на назначения из профилей приложений.
При выключении отменяются уже начатый жест и отложенные щелчки.

## Начальные назначения

Для трёхкнопочной мыши используется **кнопка 3 — нажатие колеса**:

| Действие | Результат |
|---|---|
| Щелчок / двойной щелчок / удержание | Средний щелчок / словарь / Quick Look |
| Удерживать + движение вверх / вниз | Mission Control / окна приложения |
| Удерживать + движение влево / вправо | Рабочие столы |
| Удерживать + вращать колесо | Масштабирование |
| Shift + удерживать + вращать | Показать рабочий стол / приложения |
| Option + удерживать + двигать | Прокрутка 360° |
| Command + удерживать + движение влево / вправо | Назад / вперёд |
| Command + щелчок | Новая вкладка |
| Control + щелчок | Сбросить масштаб; в нативном пресете — Smart Zoom |

Обычный средний щелчок ждёт интервал двойного щелчка. Для мгновенного среднего
щелчка удалите двойное назначение или используйте Shift + щелчок колеса.
Удержание Quick Look использует пробел и зависит от текущего контекста.

Альтернативный пресет для **мыши с 5 кнопками**:

| Кнопка | Действие | Результат |
|---|---|---|
| 4 | Щелчок | Словарь (системное сочетание) |
| 4 | Потянуть вверх / вниз | Mission Control / окна приложения |
| 4 | Потянуть влево / вправо | Рабочий стол слева / справа |
| 4 | Удерживать + колесо вверх / вниз | Рабочий стол / Launchpad или папка «Программы» |
| 5 | Щелчок | Назад |
| 5 | Потянуть влево / вправо | Назад / вперёд |
| 5 | Удерживать + колесо вверх / вниз | Увеличить / уменьшить через ⌘+/⌘− |

Пресеты меняют назначения целиком. Нативный пресет для 3 кнопок заменяет
Control + щелчок на Smart Zoom, а масштабирование колесом — на pinch.
Нативный пресет для 5 кнопок заменяет действия кнопки 5 на Smart Zoom, свайп
и pinch. Пресет «Прокрутка 360°»
назначает кнопку 5 для свободного движения по холсту.

## Совместимость и оставшиеся задачи

Подробное сравнение: [FEATURE_PARITY.md](FEATURE_PARITY.md). Эта сборка ещё не
заявляется полной заменой Mac Mouse Fix.

- Не реализованы интерактивные переходы Dock/Spaces с движением за указателем,
  фазы инерции трекпада и идентификация источника по HID-устройству.
- Непрерывные события пропускаются: это сохраняет поведение трекпада, но также
  оставляет без обработки высокоточные колёса и Magic Mouse. Общее CGEvent API
  не даёт надёжно различить эти источники. Проприетарные кнопки драйверов могут
  отсутствовать в стандартном потоке событий.
- Нативные жесты используют недокументированный формат Quartz. Тесты подтверждают
  декодирование локальной macOS; они не подтверждают принятие Safari, Mail,
  Preview или другой версией macOS. Режим через клавиши остаётся доступен.
- Системные действия учитывают существующие symbolic hotkeys и не изменяют их.
  Отключённое сочетание нужно включить в настройках клавиатуры самостоятельно.
  На macOS без Launchpad открывается папка «Программы».
- Масштабирование клавишами и команды назад/вперёд зависят от приложения и его
  раскладки/сочетаний. Для нестандартных команд используйте запись клавиш.
- Нет механизма автообновления, подписанной/notarized публичной сборки,
  автоматического переноса настроек MMF и профилей отдельных устройств.

Настройки: `~/Library/Application Support/MouseCraft/settings.json`.
При ошибке чтения исходный файл резервируется перед первой записью.
Формат нативных событий изолирован в `Sources/MouseCraftNative`; общий алгоритм
прокрутки, распознавание жестов и конфигурация — в `Sources/MouseCraftCore`.

## Проверка на физической мыши

После выдачи разрешений проверьте:

1. Направление и короткую/длинную прокрутку в Safari и тестовом списке.
2. Смена направления прекращает старое движение; клик останавливает инерцию.
3. Трекпад сохраняет направление и плавность; ⇧/⌃/⌥ работают только для колеса.
4. Кнопки 4/5, удержание, двойной щелчок: жест не вызывает лишний щелчок.
5. Mission Control, Exposé и рабочие столы при включённых системных сочетаниях.
6. Переключение приложений выбирает профиль; исключённое приложение не меняется.
7. Пауза, закрытие окна, сон/пробуждение и повторный запуск.
8. Отдельно: pinch и Smart Zoom в Safari/Preview; нативный свайп и горизонтальная
   фазовая прокрутка в Safari/Mail. Зафиксировать модель мыши, macOS и результат.

Автоматические тесты не отправляют события в систему и не выдают разрешения.
