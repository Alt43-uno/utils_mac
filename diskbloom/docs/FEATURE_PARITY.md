# Сопоставление с DaisyDisk

Источники: [Tech Specs](https://daisydiskapp.com/specs/), [Disk map](https://daisydiskapp.com/guide/4/en/UnderstandingSunburst/), [Collector](https://daisydiskapp.com/guide/4/en/DeletingFiles/), [Snapshots](https://daisydiskapp.com/guide/4/en/Snapshots/), [Cloud scan](https://daisydiskapp.com/guide/4/en/CloudScan/). Проверено 6 октября 2026 года.

«Реализовано» означает наличие работающего кода; это не утверждение об идентичной производительности и коммерческой зрелости. Отдельно указаны непроверенные внешние интеграции.

| Возможность | DiskBloom | Проверка / различия |
| --- | --- | --- |
| Подключённые диски, ёмкость, свободное место | Реализовано | Реальные внутренний и сетевой тома видны в интерфейсе |
| Папки, внешние и смонтированные сетевые диски | Реализовано | POSIX-обход любого доступного macOS пути; на сеть влияет задержка сервера |
| Несколько сканирований | Реализовано | Независимые фоновые задания и токены отмены; один текущий просмотр |
| Sunburst, наведение, drill-down, возврат, группы мелких объектов | Реализовано | Геометрия проверена тестами; навигация — в работающем приложении |
| Крупные файлы, поиск, сведения | Реализовано | Поиск по текущему поддереву; 500 отображаемых результатов, 200 крупных файлов |
| Quick Look и Finder | Реализовано | Тестовый текстовый файл действительно открыт в системном Quick Look |
| Collector, drag-and-drop, просмотр перед удалением | Реализовано | Добавление и снятие выбора проверены в UI |
| Удаление с пятисекундной отменой | Реализовано | Корзина по умолчанию; переключатель безвозвратного режима; actual UI deletion пользовательских файлов не выполнялась |
| Защита системных папок | Реализовано | Тесты root, home, system, Data firmlink и symlink parent; дополнительные проверки содержимого папок |
| Точный размер блоков, sparse files, hard links | Реализовано | Тесты реальных sparse-файлов и жёстких ссылок |
| Исключение разделяемых блоков APFS-клонов | **Не реализовано** | `st_blocks` может учитывать одинаковые разделяемые блоки несколько раз |
| Неучтённое место, другие тома, доступное и purgeable | Частично | Разница занято/измерено, сведения контейнера, оценка macOS. Нет полного разложения скрытых категорий |
| Full Disk Access | Реализовано | Инструкция и открытие настроек; разрешение предоставляет владелец Mac |
| Scan as administrator | Реализовано, требует проверки авторизации | Одноразовый worker через macOS; UI не обходит TCC; без privileged deletion |
| APFS-снимки: список и удаление | Частично | Показаны все доступные снимки, удаляются только purgeable Time Machine; нет оценки размера отдельных снимков |
| Принудительное освобождение purgeable | Частично | `tmutil thinlocalsnapshots` с запросом до 10 ГБ. Другие категории не принуждаются |
| Dropbox, Google Drive, OneDrive, Box | Реализовано, требует live OAuth QA | Поставляется rclone; OAuth-мастер, сканирование, квота, удаление, несколько аккаунтов. Реальный rclone проверен на локальном backend |
| Учёт облачной квоты общих/виртуальных файлов | **Не полный паритет** | Метаданные и quota API rclone; нет собственной нормализации правил каждого провайдера |
| Облачный Quick Look | Частично | Загрузка выбранного файла до 200 МБ по действию пользователя; не применяется при сканировании |
| iCloud | Локальная папка | Без загрузки placeholder-файлов при сканировании |
| Клавиатура и жесты | Основные реализованы | Меню команд, Space, Cmd-Delete, история, pinch; не все multi-touch gestures оригинала |
| Языки | Русский и английский | Оригинал заявляет 14 языков |
| Privacy / отсутствие аналитики | Реализовано | Локальное чтение метаданных, отсутствие серверов DiskBloom, отдельный приватный OAuth-конфиг |
| Apple Silicon / Intel | Сборка для текущей архитектуры | arm64 собрана и проверена; Intel не проверен, universal binary не подготовлен |
| Коммерческий релиз, подпись, notarization, обновления | **Не готово** | Ad hoc-сборка; нужны Developer ID и отдельный процесс релиза |
| Скорость и зрелость на уровне DaisyDisk | **Не подтверждено** | 25 000 файлов: 0,133 с на тестовом дереве; отсутствуют сравнительные и длительные испытания |

Приоритеты для полного паритета: физический учёт APFS shared extents, точные оценки снимков, provider-specific облачная квота, live OAuth QA четырёх сервисов, аудит удаления/авторизации, Intel/macOS-матрица, доступность с VoiceOver, notarization и воспроизводимый процесс обновлений.
