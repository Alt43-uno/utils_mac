Нативный анализатор дисков для macOS, созданный по мотивам сценариев DaisyDisk. Собственный код, название и графика. SwiftUI отвечает за окно и панели, AppKit/Core Graphics — за интерактивную карту и Quick Look.

## Запуск

**[DiskBloom 0.1.0 Preview · DMG для Apple Silicon](https://github.com/Alt43-uno/utils_mac/releases/download/diskbloom-v0.1.0/DiskBloom-0.1.0-arm64.dmg)** · [ZIP](https://github.com/Alt43-uno/utils_mac/releases/download/diskbloom-v0.1.0/DiskBloom-0.1.0-arm64.zip) · [SHA-256](https://github.com/Alt43-uno/utils_mac/releases/download/diskbloom-v0.1.0/DiskBloom-0.1.0-arm64.sha256)

Откройте DMG и перенесите приложение в Applications. Это предварительный выпуск с подписью ad hoc, без notarization. При блокировке запуска следуйте [инструкции Apple для приложения, которому доверяете](https://support.apple.com/102445). Intel-сборка в релиз не включена.

Готовая сборка: **`build/DiskBloom.app`**. Архив для переноса: **`build/DiskBloom.zip`**. Для создания версионных DMG, ZIP и SHA-256 после сборки выполните `Scripts/make_release.sh --no-build`; файлы появятся в `dist/`.

```bash
cd diskbloom
Scripts/build_app.sh --cloud
open build/DiskBloom.app
```

Для разработки и демонстрации:

```bash
Scripts/build_app.sh --cloud --debug
open -n build/DiskBloom.app --args --demo
# Сканировать конкретную папку при запуске:
open -n build/DiskBloom.app --args --scan /absolute/folder
```

Демонстрационные данные явно отмечены и не допускают удаления. Обычный запуск показывает реальные подключённые тома; сканирование начинается по выбору пользователя.

Требования: macOS 14+, Swift 6.2+ / актуальные Command Line Tools. Xcode не обязателен. Сборка создаётся для архитектуры текущего Mac: Apple Silicon или Intel. На этом компьютере проверена arm64-сборка; Intel и macOS 14 отдельно не проверены.

## Что работает

- Обзор подключённых локальных, внешних и смонтированных сетевых томов, ёмкость и свободное место, обновление при подключении/отключении дисков.
- Сканирование произвольных папок, несколько независимых заданий, прогресс и отмена. Чтение метаданных без чтения содержимого файлов.
- Размер занятых блоков и логический размер. Разреженные файлы, жёсткие ссылки, недоступные папки, символические ссылки и облачные placeholder-файлы учитываются отдельно.
- Карта sunburst: до семи видимых уровней, подсветка, переход в папку, возврат через центр, история, жест масштабирования и группировка мелких объектов. Вложенность глубже семи уровней доступна через переходы.
- Список с сортировкой по размеру, поиск по текущему поддереву, крупные файлы, метаданные и копирование пути. В списке показываются 500 результатов; поиск находит остальные.
- Системный Quick Look, открытие расположения в Finder, меню файла и клавиатурные команды.
- Перетаскивание объектов с карты и списка в коллекцию. Коллекция объединяет пересекающиеся папки, позволяет пересмотреть выбор и убрать объекты до удаления.
- Перемещение в Корзину по умолчанию; опциональное безвозвратное удаление. Подтверждение и пятисекундная отмена. Проверка идентичности файлов и всего поддерева непосредственно перед удалением. Системные пути, корни томов и домашняя папка защищены.
- Сканирование с правами администратора через отдельный **read-only** worker и системную авторизацию macOS. Полный доступ к диску всё равно предоставляется пользователем в настройках системы.
- Просмотр APFS-снимков и других томов контейнера. Удаление освобождаемых снимков Time Machine и запрос освобождения до 10 ГБ через `tmutil`; защищённые снимки не удаляются.
- Dropbox, Google Drive, OneDrive и Box через rclone: мастер OAuth в окне приложения, несколько аккаунтов, удалённое сканирование без скачивания, квота при поддержке провайдером, проверка изменений перед удалением. Предпросмотр отдельного облачного файла скачивает только выбранный файл, до 200 МБ.
- CSV/JSON-экспорт, русский/английский интерфейс, собственная иконка, `.app` и ZIP-сборки.

## Повседневный сценарий

1. Выберите диск или нажмите «Выбрать папку…». Можно перетащить папку из Finder на окно.
2. Нажмите «Сканировать». Для полного сканирования диска включите **Настройки системы → Конфиденциальность и безопасность → Полный доступ к диску → DiskBloom**, затем перезапустите приложение.
3. Кликните сектор папки на карте или стрелку рядом с папкой в списке. Наведение показывает её размер; кнопка в центре возвращает вверх.
4. Просмотрите файл через Quick Look. Добавьте ненужные объекты в коллекцию кнопкой, меню, `⌘⌫` или перетаскиванием.
5. Нажмите «Проверить». После подтверждения остаётся пять секунд на отмену. Для Корзины место освобождается только после её очистки; приложение само Корзину не очищает.

После удаления выполняется повторное сканирование затронутых источников. При ошибке неудавшиеся объекты остаются в коллекции. Обновившийся после сканирования объект требуется сначала пересканировать и выбрать заново.

| Команда | Сочетание |
| --- | --- |
| Выбрать папку | `⌘O` |
| Повторить сканирование | `⌘R` |
| Quick Look | `Space` |
| В коллекцию | `⌘⌫` |
| Родительская папка | `⌘↑`, `Esc` при фокусе карты |
| Назад / вперёд | `⌘[` / `⌘]` |
| Коллекция | `⌘K` |
| Экспорт | `⌘E`, меню «…» |
| Настройки | `⌘,` |

## Облачные аккаунты

`--cloud` включает rclone **1.75.1**, скачанный с официального сервера с проверкой SHA-256. Ничего не устанавливается глобально. Без этого флага можно использовать rclone из `/opt/homebrew/bin` или `/usr/local/bin`.

В разделе «Облачные диски» нажмите «Подключить аккаунт», выберите сервис и задайте уникальное название латиницей. OAuth открывается в браузере через приложение rclone. Ответьте на дополнительные вопросы провайдера в мастере. Пароль провайдера не вводится в DiskBloom.

Конфигурация и OAuth-токены находятся в `~/Library/Application Support/DiskBloom/rclone.conf`; каталог имеет права `0700`, завершённый файл — `0600`. Токены не включаются в отчёты. Удаление подключения стирает локальную конфигурацию; отозвать разрешение у провайдера можно в настройках его аккаунта. Предпросмотры находятся в `~/Library/Caches/DiskBloom/Previews` и очищаются при нормальном выходе/следующем запуске.

Облачное удаление использует правила сервиса: оно может перемещать в корзину провайдера либо удалять безвозвратно. Это явно указано в подтверждении. DiskBloom не создаёт публичные ссылки. OAuth с реальными учётными записями требует проверки владельцем аккаунтов; автоматические проверки используют локальный backend rclone без сети.

## Проверка

```bash
Scripts/test.sh
codesign --verify --deep --strict build/DiskBloom.app
```

36 тестов проверяют файловую систему, защиту удаления, изменение вложенных файлов, геометрию карты, CSV/JSON, subprocess I/O и отмену. Четыре интеграционных теста используют настоящий rclone на временных данных внутри `.build`, включая успешное удаление тестового файла и отказ при изменениях. Файлы пользователя в тестах не удаляются.

Во время UI-проверки подтверждены сканирование тестовой папки, переходы, поиск с пробелами, Quick Look, добавление/удаление из коллекции и сохранение CSV-отчёта (10 узлов, 5 файлов). Для контрольного дерева из 25 000 файлов по 4096 байт релизный worker измерил 102 400 000 байт за **0,133 с**; полный процесс с JSON-выводом занял **0,28 с** и до **110 МБ RSS**. Это результат синтетического дерева на этом Mac с прогретым кэшем, а не обещание скорости полного диска и не сравнительный тест DaisyDisk.

## Границы готовности

Рабочая реализация основных сценариев готова, но **полный паритет с коммерческим DaisyDisk не подтверждён**. Точная таблица — [docs/FEATURE_PARITY.md](docs/FEATURE_PARITY.md).

- `st_blocks` учитывает реально выделенные блоки каждого файла и дедуплицирует жёсткие ссылки. **Уникальные разделяемые блоки APFS-клонов не дедуплицируются**. Поэтому это не точная оценка физически освобождаемого места.
- Размер отдельных APFS-снимков не оценивается. «Неучтённое место» — разница общего занятого места контейнера и доступных сканеру файлов; сюда также входят другие тома, снимки, метаданные и ограничения доступа.
- Очистка освобождаемого места ограничена документированным запросом к Time Machine. Кэши macOS и остальные категории purgeable не удаляются автоматически.
- Облачный размер — размер из метаданных rclone. Провайдерские правила квоты общих файлов и виртуальных документов могут отличаться. Облачный предпросмотр ограничен 200 МБ.
- Administrator worker только сканирует; удаление файлов не повышает привилегии. Изменение файла между последней проверкой и системным удалением остаётся возможным: проверка не является транзакционной блокировкой файловой системы. Приложение предназначено для ручной очистки собственных данных, а не для работы в недоверенной многопользовательской среде.
- Нет Developer ID / notarization, автообновления, коммерческого лицензирования, оценки скорости относительно DaisyDisk и остальных 12 языков оригинала. Подпись сборки ad hoc; для распространения пользователям необходим подписанный и нотарифицированный релиз.

Сборочный wrapper обходит две проблемы конкретных preview Command Line Tools: устаревший private-интерфейс PackageDescription (локальная копия внутри `.build`) и неполный SwiftUI-macro plugin в SDK 27 (используется установленный SDK 26.5). Системный toolchain не изменяется.

## Структура

```text
Sources/DiskBloomCore/       Сканеры, модели, безопасность, APFS, геометрия, экспорт
Sources/DiskBloom/           SwiftUI/AppKit-приложение и OAuth-мастер
Sources/DiskBloomWorker/     Одноразовый сканер для системной авторизации
Tests/DiskBloomCoreTests/    36 тестов Swift Testing
Resources/                  Info.plist, privacy manifest, иконка, лицензия rclone
Scripts/                    Сборка, тесты, проверяемая загрузка rclone
docs/                       Паритет и архитектура
build/                      .app и ZIP, не включаются в Git
```

Лицензия исходного кода — лицензия корневого репозитория. Условия rclone включены в `Resources/ThirdPartyNotices.txt` и в приложение.
